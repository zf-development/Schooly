# 🎯 Objectif du dossier client

Ce dossier contient toute la partie front-end du projet Schooly. Il est développé en **ReactJS** avec **Mantine UI** pour les composants visuels.  
Les données sont récupérées via Supabase et via une API REST (backend Node).

---

# 📁 Structure des sous-dossiers

-   `/components` → Composants UI réutilisables (ex: boutons, cards, inputs)
-   `/pages` → Pages de navigation (ex: FeedPage, LoginPage)
-   `/layouts` → Layouts globaux de l'application (ex: MainLayout)
-   `/hooks` → Custom hooks pour la logique (ex: `useUser`)
-   `/services` → Communication avec Supabase ou API backend
-   `/contexts` → Gestion du contexte utilisateur / école
-   `/utils` → Fonctions utilitaires (formatage, constantes)
-   `main.tsx` → Entrée de l’app React

---

# ✅ Bonnes pratiques à suivre

-   Utiliser Mantine pour tous les composants UI
-   Typage strict avec TypeScript
-   Créer un composant par fichier, nom explicite
-   Ne pas réécrire un fichier complet pour un petit changement
-   Toujours demander à l'humain **avant de cocher une tâche**

---

# ⚠️ Ce que tu ne dois pas faire

-   Ne pas modifier plusieurs composants à la fois
-   Ne pas introduire de logique métier dans les pages
-   Ne pas écrire de logique backend ici
