# 📦 StudBud – Spécifications des Components (React + Mantine)

---

## 🏠 Layout & Structure

### 1. MainLayout
| Prop | Type | Description |
|------|------|-------------|
| `children` | `React.ReactNode` | Contenu principal de la page |

**Description** : Layout global avec Header et Footer, MantineProvider et styles globaux.

---

### 2. Header
| Prop | Type | Description |
|------|------|-------------|
| `onInstitutionChange` | `(id: string) => void` | Callback pour changement d’école |

**Description** : Barre de navigation avec logo, `InstitutionSelector`, `AuthButton`.

---

### 3. Footer
| Prop | Type | Description |
|------|------|-------------|
| _(none)_ | _(none)_ | Pas de props pour MVP |

**Description** : Footer simple avec liens statiques.

---

## 🔐 Auth

### 4. AuthButton
| Prop | Type | Description |
|------|------|-------------|
| `isAuthenticated` | `boolean` | Indique si l’utilisateur est connecté |
| `onLogin` | `() => void` | Callback clic connexion |
| `onLogout` | `() => void` | Callback clic déconnexion |

---

### 5. LoginForm
| Prop | Type | Description |
|------|------|-------------|
| `onSubmit` | `(email: string, password: string) => void` | Callback soumission formulaire |
| `loading` | `boolean` | Affiche un loader si true |

---

## 📰 Feed & Posts

### 6. PostCard
| Prop | Type | Description |
|------|------|-------------|
| `author` | `{ id: string; name: string; institution: string; }` | Auteur du post |
| `content` | `string` | Texte du post |
| `visibility` | `'public' \| 'private'` | Visibilité du post |
| `createdAt` | `string \| Date` | Date de création |

---

### 7. PostForm
| Prop | Type | Description |
|------|------|-------------|
| `onSubmit` | `(content: string, visibility: 'public' \| 'private') => void` | Callback création post |
| `loading` | `boolean` | Loader de soumission |

---

### 8. FeedList
| Prop | Type | Description |
|------|------|-------------|
| `posts` | `Post[]` | Liste des posts |
| `loading` | `boolean` | Loader affiché si true |

---

## 🏫 Institutions

### 9. InstitutionSelector
| Prop | Type | Description |
|------|------|-------------|
| `institutions` | `{ id: string; name: string; logoUrl?: string; }[]` | Liste des écoles |
| `selectedId` | `string` | ID de l’école sélectionnée |
| `onChange` | `(id: string) => void` | Callback changement d’école |

---

## ⚙️ Utilitaires

### 10. LoaderOverlay
| Prop | Type | Description |
|------|------|-------------|
| `visible` | `boolean` | Affiche ou cache le loader |

---

### 11. ErrorAlert
| Prop | Type | Description |
|------|------|-------------|
| `message` | `string` | Message d’erreur |
| `onClose?` | `() => void` | Callback fermeture |

---

### 12. NotificationToast
| Prop | Type | Description |
|------|------|-------------|
| `message` | `string` | Message à afficher |
| `type` | `'success' \| 'error' \| 'info'` | Type de notification |
